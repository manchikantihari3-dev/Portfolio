# Manchikanti Harinadh Babu - Personal Portfolio

A modern, responsive, and beautifully designed personal portfolio showcasing my projects, skills, and achievements. Built purely with HTML, CSS, and JavaScript.

## Features
- 🎨 **Modern Dark Theme**: Premium glassmorphism design with glowing accents.
- 📱 **Fully Responsive**: Optimized for mobile, tablet, and desktop views.
- ✨ **Interactive Animations**: Smooth scrolling, scroll-reveal effects, and dynamic navbar.
- 🚀 **Fast & Lightweight**: Built with standard web technologies (No build step required).

## Tech Stack
- HTML5
- CSS3 (Vanilla, custom properties, Flexbox/Grid)
- JavaScript (DOM Manipulation, Intersection Observer)
- FontAwesome (Icons)
- Google Fonts (Inter, Outfit)

## Getting Started
To view this project locally, simply clone the repository and open `index.html` in your web browser. No installation or build process is required!

```bash
git clone https://github.com/manchikantihari3-dev/portfolio.git
cd portfolio
# Open index.html in your browser
```
